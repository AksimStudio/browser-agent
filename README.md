# Autonomous Browser Agent

Автономный браузерный агент на Node.js. Codex CLI или OpenAI управляет видимым persistent Chromium через Playwright, исследует незнакомые страницы и работает с компактным DOM-снимком.

## Возможности

- видимый Playwright Chromium и постоянный профиль `.browser-profile`;
- backend Codex CLI без отдельного API-ключа;
- опциональный backend OpenAI API;
- интернет-поиск, навигация, клики, ввод, выбор, прокрутка и ожидание;
- локальный DOM sub-agent ранжирует элементы и сокращает контекст;
- старые снимки страницы не накапливаются в контексте;
- ограниченная память фактов и последних действий;
- снимки окна через `take_screenshot`;
- визуальный анализ снимков в Codex CLI и OpenAI API;
- управляемое закрытие HTML-попапов через `dismiss_popup`;
- программный запрет придуманных внутренних URL;
- адаптация после ошибок и запрет повторения неудачного действия;
- подтверждение перед оплатой, удалением, отправкой и вводом секретов;
- журнал действий и результатов в терминале.

## Установка

```bash
git clone <URL-репозитория>
cd browser-agent
npm install
npx playwright install chromium
cp .env.example .env
```

Требования: Node.js 18 или новее. Для режима Codex CLI также установите Codex и выполните `codex login`. Для режима OpenAI API достаточно указать ключ в `.env`.

## Codex CLI — режим по умолчанию

Codex должен быть установлен, а пользователь должен предварительно выполнить вход:

```bash
codex login
npm start
```

Конфигурация:

```dotenv
AI_PROVIDER=codex
# CODEX_BIN=codex
# CODEX_MODEL=
```

На каждом шаге запускается изолированный `codex exec`. Он получает ограниченное состояние страницы и выбирает одно следующее действие. Codex работает в read-only sandbox; реальные браузерные действия выполняет Playwright после проверки security layer.

Для ограничения расхода токенов один Codex thread используется максимум четыре шага (`CODEX_THREAD_STEPS=4`), затем переносится только текущее компактное состояние и короткая история действий.

Агент запускает комплектный Playwright Chromium с отдельным профилем `.browser-profile`, поэтому его можно использовать одновременно с личным браузером.

## OpenAI API

Чтобы использовать API вместо Codex CLI:

```dotenv
AI_PROVIDER=openai
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-5-mini
# OPENAI_BASE_URL=https://api.openai.com/v1
```

Затем запустите `npm start`. Откроется Chromium; перед вводом задачи можно авторизоваться на нужном сайте вручную. Профиль сохраняется между запусками.

## Безопасная демонстрация

В первом терминале:

```bash
npm run demo
```

Во втором:

```bash
npm start
```

Пример задачи:

```text
Открой http://127.0.0.1:4173, изучи письма, удали только очевидный спам после моего подтверждения и дай отчёт.
```

## Архитектура

Подробное исследование альтернатив, принятые решения и известные риски описаны в [`docs/TECHNICAL_DECISIONS.md`](docs/TECHNICAL_DECISIONS.md).

- `src/cli.js` — запуск, выбор backend и запрос подтверждений;
- `src/config.js` — конфигурация Codex CLI/OpenAI;
- `src/codex-client.js` — адаптер неинтерактивного `codex exec`;
- `src/agent.js` — автономный цикл с ограниченной памятью;
- `src/dom-agent.js` — фильтрация и ранжирование DOM;
- `src/browser.js` — управление Playwright;
- `src/security.js` — независимый барьер опасных действий;
- `demo/server.js` — безопасный локальный сценарий.

Агент не обходит CAPTCHA и антибот-защиту. Оплата, удаление и отправка данных выполняются только после явного подтверждения пользователя.
